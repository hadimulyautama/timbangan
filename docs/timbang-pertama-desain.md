# Timbang pertama

Susunan desktop dan ponsel mengikuti mockup yang disetujui 7 November 2026.
Berat dan kondisi truk, pihak, kendaraan dan tindakan simpan menjadi prioritas.
Jenis, arah dan penanda titipan jasa tetap terlihat. Dokumen dan muatan tetap
memakai disclosure lama; pada jasa timbang bebas pilihan sekali/dua kali tetap
terlihat karena menentukan cara menyimpan.

Tombol ⓘ Panduan memakai kerangka `_panduan.html` dan `panduan.css` yang
disalin identik dari komponen PadiFlow. Isi dibuat khusus alur timbang pertama,
termasuk aturan dari master, kapasitas, hubungan Produksi, kontak, waktu,
nomor perkiraan dan status penyimpanan. Tanpa JavaScript konten tersedia dalam
disclosure di bawah formulir. Dengan JavaScript node konten yang sama masuk
dialog native, dapat ditutup lewat tombol atau Escape dan fokus kembali ke
pembuka.

Jam timbang tetap satu input datetime-local di form asli, dibuka lewat Ubah.
Label mengikuti isian dan pemulihan draf. Seluruh field, nilai, presisi,
kewajiban, action, metode dan handler penyimpanan/luring tetap. Tidak ada
perubahan backend, migrasi, otorisasi, timbang kedua atau koreksi.

Paket dibuat dari origin/main `0ce1c86` agar perubahan kerja lain tidak ikut.
Penerapan belum merupakan rilis.
